# 🎓 EduGenie

## Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant built using Python, Streamlit, and Google Gemini.

## ✨ Features

- 💬 Ask educational questions
- 📖 Explain topics in simple language
- 📝 Summarize study notes
- 🧠 Generate multiple-choice quiz questions
- 🎓 Useful for student learning and revision
